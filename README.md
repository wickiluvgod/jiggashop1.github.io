# JIGGA SHOP

Minimal streetwear storefront concept for JIGGA SHOP.

## Open in VS Code

1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension.
4. Or simply open `index.html` in your browser.

## GitHub Pages

1. Create a new repository on GitHub, for example `jigga-shop`.
2. Upload **everything inside this folder**, keeping the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will publish the site.

The site uses relative paths, so it works locally in VS Code and as a GitHub Pages site.
